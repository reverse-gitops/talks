REVERSER · CONFIG AS KRM
Design it so it can remember.
Config as Kubernetes resources (KRM): not just the value, but the why, the expiry, the last test.
01 Model StroopwafelOrderer’s config as Kubernetes resources (KRM). One rule: any secret field goes into its own Secret.
02 The ApiKey records what we meant: its rights, its expiry, the ticket. The value sits in a SOPS-encrypted Secret.
03 A controller writes what happened: last tested, last used. Spec is reviewed in Git; status never goes there.
04 The app decrypts with its own workload identity. Anyone may read the ApiKey; only the app reads the key.
