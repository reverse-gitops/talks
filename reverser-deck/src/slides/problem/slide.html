THE PROBLEM
One typo. No more customer emails.
Settings often live in the app’s database, next to the orders. One small edit can break production, and it is not always clear what happened.
01 Every order sends a confirmation email through SendGrid, with an API key stored in the app’s settings.
02 A power user updates the key on the settings page. One character is off.
03 Orders still succeed. But every email now fails with 401 Unauthorized, and customers hear nothing.
04 Some apps handle this well. Many don’t, and you find out in production.
